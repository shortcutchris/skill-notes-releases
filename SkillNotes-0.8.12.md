# Skill Notes 0.8.12

Free Prompt adds a fast path for instructions you need once.

It is always the first item in the Skills palette and opens directly with
Shift-Command-K from the active sticky note. Choose the exact target, result
behavior, and either Local or OpenAI, then press Return or Run Once. The
instruction is not saved and the normal result preview still appears before
anything can change.

If the instruction turns out to be useful again, Save as Skill creates a
normal reusable custom skill and can pin it to the sticky-note toolbar.

## Deutsch

„Freier Prompt“ ergänzt einen schnellen Weg für Anweisungen, die nur einmal
benötigt werden.

Er steht dauerhaft an erster Stelle der Skill-Palette und öffnet sich in der
aktiven Haftnotiz direkt mit Umschalt-Befehl-K. Wähle Ziel, Ergebnisverhalten
und lokal oder OpenAI und drücke Return beziehungsweise „Einmalig ausführen“.
Die Anweisung wird nicht gespeichert; bevor sich etwas ändern kann, erscheint
weiterhin die normale Ergebnisvorschau.

Soll die Anweisung künftig wiederverwendet werden, erzeugt „Als Skill
speichern …“ einen normalen eigenen Skill und kann ihn direkt an die
Symbolleiste der Haftnotiz anheften.

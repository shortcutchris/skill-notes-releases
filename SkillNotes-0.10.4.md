# Skill Notes 0.10.4

## English

### Open notes form a readable workspace

- **Window → Arrange Open Notes** returns every open sticky note to its
  creation size and lays the notes out from left to right in centered rows on
  the display where the command is invoked.
- The layout keeps a readable minimum size and never overlaps notes. If the
  current display is full, additional notes continue on the nearest available
  display.
- Collapsed and minimized notes are made readable for the arranged view while
  their favorite state, floating window level, and workspace membership remain
  unchanged.
- **Window → Restore Previous Note Arrangement** returns all affected notes to
  their previous frames, collapsed state, and minimized state in one step.
- Home records the resulting positions only when window-position memory is
  enabled. A named workspace marks its layout as changed so the user remains in
  control of whether to save it.

The arrangement is entirely Mac-local. It does not change note content,
attachments, tasks, favorites, or synchronized workspace definitions.

# Skill Notes 0.10.4

## Deutsch

### Geöffnete Notizen bilden eine gut lesbare Arbeitsfläche

- **Fenster → Geöffnete Notizen anordnen** bringt alle geöffneten Haftnotizen
  auf ihre Ursprungsgröße zurück und ordnet sie auf dem Monitor des Aufrufs von
  links nach rechts in zentrierten Reihen an.
- Das Raster hält eine gut lesbare Mindestgröße ein und verhindert
  Überlappungen. Ist der aktuelle Monitor voll, werden weitere Notizen auf dem
  nächstgelegenen verfügbaren Monitor fortgesetzt.
- Eingeklappte und minimierte Notizen werden für die angeordnete Ansicht
  lesbar geöffnet. Favoritenstatus, schwebende Fensterebene und
  Arbeitsflächenzuordnung bleiben unverändert.
- **Fenster → Vorherige Notizanordnung wiederherstellen** setzt alle
  betroffenen Notizen in einem Schritt auf ihre vorherigen Rahmen sowie ihren
  eingeklappten und minimierten Zustand zurück.
- „Start“ speichert die neuen Positionen nur, wenn das Merken von
  Fensterpositionen aktiviert ist. Bei einer benannten Arbeitsfläche wird das
  Layout als geändert markiert, sodass der Nutzer weiterhin selbst entscheidet,
  ob es gespeichert wird.

Die Anordnung bleibt vollständig lokal auf dem Mac. Sie verändert weder
Notizinhalte, Anhänge, Aufgaben, Favoriten noch synchronisierte
Arbeitsflächendefinitionen.

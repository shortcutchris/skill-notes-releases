# Skill Notes 0.9.0

This feature release introduces visual text formatting while preserving the dependable plain-text foundation of every note.

## Highlights

- Format text directly with headings, bold, italic, bulleted lists, numbered lists, checklists, and links.
- Use the compact formatting bar below the title bar without exposing Markdown markers in the editor.
- Turn selected text or the current line into a checklist item that also appears in the central task overview.
- Paste formatted text with a clear choice between plain text and supported formatting.
- Keep exact cursor positions, selections, replacements, and single-step undo behavior across formatting actions.
- Exchange notes safely through the CLI and MCP interfaces using the documented, canonical text format.

Notes remain stored as portable UTF-8 Markdown. Unsupported presentation markup is not introduced, and note content is only sent to OpenAI after an explicit AI action.

# Skill Notes 0.9.0

Dieses Funktionsupdate führt eine visuelle Textformatierung ein und bewahrt gleichzeitig die verlässliche Klartextbasis jeder Notiz.

## Highlights

- Texte direkt mit Überschriften, Fett, Kursiv, Aufzählungen, nummerierten Listen, Aufgabenlisten und Links formatieren.
- Die kompakte Formatierungsleiste unterhalb der Titelleiste verwenden, ohne Markdown-Zeichen im Editor sehen zu müssen.
- Markierten Text oder die aktuelle Zeile in eine Aufgabe umwandeln, die zugleich in der zentralen Aufgabenübersicht erscheint.
- Beim Einfügen formatierter Inhalte bewusst zwischen Klartext und unterstützter Formatierung wählen.
- Cursorposition, Auswahl, Ersetzung und einheitliches Rückgängigmachen bleiben bei allen Formatierungsaktionen präzise erhalten.
- Notizen sicher über CLI und MCP im dokumentierten, kanonischen Textformat austauschen.

Notizen bleiben als portables UTF-8-Markdown gespeichert. Nicht unterstützte Präsentationsauszeichnungen werden nicht eingeführt, und Inhalte werden nur nach einer ausdrücklich ausgelösten KI-Aktion an OpenAI gesendet.

# Skill Notes 0.12.1

## English

### Cleaner checklist entry

- A newly created checkbox now leaves a clear one-space visual gap before the
  insertion cursor and the text you type next.
- Toolbar formatting, `x` followed by Space, continued checklist lines, and
  agent-created tasks retain the same canonical Markdown structure.

# Skill Notes 0.11.2

## English

### Natural stacking between normal notes and favorites

- Clicking a normal note now temporarily raises it above always-on-top
  favorites, so the selected note always remains fully visible and editable.
- As soon as the normal note loses focus, it returns to the standard macOS
  window level and favorites resume their always-on-top behavior.
- The temporary focus behavior never changes or synchronizes the note's
  favorite state and is not stored in workspace layouts.

# Skill Notes 0.11.2

## Deutsch

### Natürliches Anordnen normaler Notizen und Favoriten

- Beim Anklicken wird eine normale Notiz jetzt vorübergehend über dauerhaft
  sichtbare Favoriten gelegt, damit die ausgewählte Notiz vollständig sichtbar
  und bearbeitbar bleibt.
- Sobald die normale Notiz den Fokus verliert, kehrt sie auf die gewöhnliche
  macOS-Fensterebene zurück und die Favoriten liegen wieder dauerhaft oben.
- Dieses temporäre Fokusverhalten verändert oder synchronisiert den
  Favoritenstatus nicht und wird nicht in Arbeitsflächen gespeichert.

# Skill Notes 0.14.0

## English

### Edit cards directly and organize notes by display

- Click a card title or body in All Notes and start editing immediately—there
  is no separate Edit button to find.
- Use Show Sticky Note to open the matching floating note or bring its existing
  window forward. Card and sticky note always share the same live content.
- From the Window menu, choose a connected display and arrange either only
  pinned notes or every open note on it. Favorite state is never changed.
- Restore Previous Note Arrangement still returns the affected notes to their
  prior frames, collapsed state, and minimized state.

# Skill Notes 0.14.0

## Deutsch

### Karten direkt bearbeiten und Notizen pro Monitor ordnen

- In „Alle Notizen“ genügt ein Klick auf Titel oder Inhalt einer Karte, um
  sofort zu schreiben – ein separater Bearbeiten-Knopf ist nicht mehr nötig.
- „Haftnotiz anzeigen“ öffnet das passende schwebende Fenster oder holt das
  bereits vorhandene nach vorne. Karte und Haftnotiz teilen immer denselben
  Live-Inhalt.
- Im Fenstermenü lässt sich ein angeschlossener Monitor auswählen. Darauf
  können wahlweise nur angeheftete oder alle geöffneten Notizen angeordnet
  werden, ohne ihren Favoritenstatus zu verändern.
- „Vorherige Notizanordnung wiederherstellen“ bringt die betroffenen Notizen
  weiterhin auf ihre vorherigen Positionen sowie in ihren vorherigen Ein- und
  Minimierungszustand zurück.

# Skill Notes 0.9.1

This maintenance update repairs visual text formatting in the macOS note
editor.

## Highlights

- Headings now render larger and bold instead of looking like ordinary body
  text.
- Bold and italic formatting is visibly applied as soon as it is selected.
- Formatting survives note resizing, editor refreshes, relaunches, and font
  changes.
- All five selectable editor font families are covered, including a readable
  italic fallback for System Rounded.

Notes remain stored as portable UTF-8 Markdown. The update changes only the
visual presentation and does not alter note content, CloudKit data, revisions,
exports, cursor mapping, or Undo behavior.

# Skill Notes 0.9.1

Dieses Wartungsupdate repariert die sichtbare Textformatierung im
macOS-Notizeditor.

## Highlights

- Überschriften erscheinen jetzt größer und fett statt wie normaler Fließtext.
- Fett- und Kursivformatierungen werden unmittelbar sichtbar angewendet.
- Formatierungen bleiben nach Größenänderungen, Editor-Aktualisierungen,
  Neustarts und Schriftwechseln erhalten.
- Alle fünf auswählbaren Schriftfamilien sind abgedeckt, einschließlich einer
  gut lesbaren Kursiv-Ersatzdarstellung für System Rounded.

Notizen bleiben als portables UTF-8-Markdown gespeichert. Das Update ändert nur
die visuelle Darstellung und nicht den Notizinhalt, CloudKit-Daten, Versionen,
Exporte, Cursor-Zuordnung oder das Rückgängigmachen.

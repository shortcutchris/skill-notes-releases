# Skill Notes 0.14.1

## Deutsch

Die Bearbeitung in der Kartenansicht fühlt sich jetzt genauso an wie in einer
schwebenden Haftnotiz. Statt einer dauerhaft eingeschobenen Werkzeugzeile gibt
es denselben kompakten Formatierungsbutton mit Popover und Link-Dialog. Dadurch
bleibt der Schreibbereich stabil und springt beim Formatieren nicht mehr.

Escape schließt nur das Formatierungs-Popover; die Karte bleibt anschließend im
Bearbeitungsmodus.

## English

Card View editing now behaves like a floating sticky note. The permanent inline
tool row has been replaced by the same compact formatting button, popover, and
link dialog, keeping the writing area stable while formatting.

Escape dismisses only the formatting popover, leaving the card in edit mode.
